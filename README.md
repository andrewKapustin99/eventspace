# EventSpace — обновлённый сайт для GitHub Pages

Полная версия от 22 октября 2026 года. HTML, CSS, JavaScript, изображения и локальные шрифты с кириллицей. Для размещения не нужны Python, npm или сборка.

## Как обновить свой сайт

1. Распакуйте архив и скопируйте всё содержимое в свою локальную папку репозитория `eventspace`, согласившись на замену файлов. Файл `index.html` должен остаться в корне.
2. Обязательно скопируйте `platform.css`, `editorial.css`, `app.js`, `index.html` и папку `assets` целиком.
3. Откройте PowerShell в этой папке:

```powershell
git add .
git commit -m "Update EventSpace design and venue spaces"
git push origin main
```

Ранее выбранные настройки GitHub Pages (`main`, `/ (root)`) сохраняются. После завершения публикации обновите страницу сочетанием Ctrl+F5.

## Главная страница

- Слайдер из четырёх площадок: стрелки, точки, автоматическая смена и кнопка паузы. Смена приостанавливается при наведении и фокусе. При prefers-reduced-motion автоматическая смена отключена.
- Новый текст о платформе EventSpace.
- Выделенная форма поиска: тип мероприятия, город и вместимость до указанного числа. Бюджет в форме на главной убран.
- Кастомные селекты с поддержкой клавиатуры. Для мероприятия доступно «Другое».
- Убраны прежняя надпись «Минск и места рядом», ссылка «Вдохновиться событиями», строка трёх преимуществ под поиском, пояснение про TOP под карточками и раздел новых площадок.
- Вместо продвижения одного конкретного кейса — общий блок о разделе кейсов.
- На телефоне форма поиска расположена перед слайдером.

Рекламные карточки продолжают иметь заметную метку «TOP · Реклама». Фиктивность предложений обозначена в footer.

## Каталог и фильтры

Показываются площадки по конкретному адресу. У каждой — одно или несколько пространств.

Тип мероприятия и тип пространства можно выбрать в нескольких значениях. Внутри одной группы работает «ИЛИ», между группами — «И».

**Вместимость до N гостей — верхняя граница:** показываются пространства, рассчитанные не более чем на N гостей. Это не проверка возможности разместить группу из N человек. Подпись и подсказка в интерфейсе поясняют правило.

Цена, вместимость, тип и оборудование проверяются у одного пространства. Например, нельзя совместить цену маленькой переговорной и оборудование большого зала. На карточке показан конкретный подходящий зал, к которому относятся цена и вместимость.

Сортировка и условная карта используют те же выбранные пространства. Город доступен отдельно от типа мероприятия. В каталоге остаётся фильтр цены за час.

## Площадки и пространства

В демонстрации 8 площадок и 15 пространств.

- Площадка: один адрес, общие контакты, описание, инфраструктура и список залов.
- Пространство: собственная галерея, цена, вместимость, площадь, оборудование, подсказки и варианты рассадки.
- «Вся площадка» оформлена как отдельный вариант аренды.
- Если пространство одно, его детали показаны сразу на странице площадки.
- Контактное окно сохраняет название выбранного пространства.

Примеры маршрутов:

- `#/venue/loft` — «Мануфактура» и три варианта аренды.
- `#/venue/loft/space/loft-main` — большой зал.
- `#/venue/loft/space/loft-meeting` — переговорная.
- `#/venue/loft/space/loft-whole` — вся площадка.
- `#/venue/line` — площадка с одним пространством.

## Избранное и сравнение

В избранном сохраняется площадка целиком. В сравнении — конкретные пространства, от двух до четырёх, в том числе из одной площадки. Сохранения используют прежние ключи localStorage. Ранее выбранные для сравнения площадки автоматически сопоставляются с их основными пространствами.

## Общий дизайн

Светлая редакционная стилистика, Cormorant Garamond и Manrope применяются ко всем страницам, включая журнал, кейсы, тарифы, формы, контакты, сравнение и состояния. Кнопки и фокус с клавиатуры оформлены в оливковой палитре. Шрифты и изображения размещены локально.

## Проверено

Синтаксис JavaScript, 48 маршрутов, 7 служебных состояний, множественные фильтры, верхняя граница вместимости, поиск по пространствам, согласованность цен и оборудования, избранное, сравнение, миграция сохранений, контекст контактов, селекты с клавиатуры и переключение слайдера прошли программные проверки.

Браузерная визуальная проверка недоступна: supervisor предпросмотра в этой среде не работает. Адаптивные стили предусмотрены для desktop, tablet и mobile; перед рабочим запуском проверьте вид в своём браузере.

Все площадки, контакты, цены, кейсы и фотографии иллюстративные. Формы имитируют отправку. Карта — условная схема. Серверная часть не входит в этот дизайн-прототип.
